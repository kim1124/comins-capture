## 실행 중 확인한 환경·요청 계약 문제

GitHub 보호 API가 빈 contexts 배열과 앱 지정 checks를 함께 받은 요청을422로 거부했다. 중복 contexts만 제거하여 같은 검사·앱 고정·관리자 보호 조건으로 적용한 후 GET으로 검증했다. 보안 조건은 완화하지 않았다.

연결된 GitHub 앱의 PR 생성은403 Resource not accessible by integration으로 거부됐다. 관리 권한이 확인된 GitHub CLI에서 승인된 동일 Draft PR을 생성했다. 자동 승인 검토 거부나 제품 코드 오류가 아니다. 보호 전후·요청 오류·push·PR·CI의 상수/공개 메타데이터는 같은 로컬 증거 디렉터리에 보존했다.
