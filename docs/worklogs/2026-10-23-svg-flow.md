## 범위와 확인한 원인

잘못 선택한 PNG 내장 허용 응답은 사용자의 후속 지시로 철회했다. SVG의 원래 HTML·텍스트·도형 구조를 유지하며, PNG/feImage 내장·강제 nowrap·폰트 변경 없이 적격한 일반 block 문단의 줄 배치를 보정한다.

기존 CSSOM 숫자 선언의 직렬화가 축소 zoom과 역 zoom을 반올림하여 WebKit의 실제 글자 폭과 픽셀 결과를 바꾸는 것을 확인했다. 기존 절대 배치 경로에도 같은 분수 배율 문제가 있다. 진단 대조에서 모든 CSSOM 편집 후 zoom 숫자만 원래 정밀도로 style 속성에 마지막 기록하면, 원본 3줄이 4줄로 바뀌던 문장이 3줄을 유지했다. 부모·형제 박스는 기존 출력과 동일했다. 이 결과는 제한된 진단이며 전체 SVG 품질 보증이 아니다.

안전한 일반 block의 native 크기를 고정하고 텍스트를 별도 배율 처리하는 방식을 적용한다. flex/grid 기준선·table/inline·float·다단 등 문맥과 패딩·테두리·혼합 인라인·RTL·생성 콘텐츠 등은 별도 근거 없이 확장하지 않는다. static을 relative로 변경할 때 원래 무시되던 inset을 활성화하지 않도록 처리하고, 여러 줄의 전체 Range rect를 변경 감지에 포함한다.

단일 역배율만으로는 내부 Float32 곱이 정확히 1이 되지 않는 비율이 남는다. 10,000개 수치 대조에서 단일 단계는 9,345개를 상쇄했고, 나머지 655개는 1에 인접한 Float32를 중간 zoom으로 추가하여 두 단계로 상쇄할 수 있었다. 실제 WebKit의 대표 미상쇄 배율에서도 약 1px 글자 차이가 줄어드는 것을 확인했다. 이 결과는 제한된 수치·실제 렌더링 대조이며 모든 배율·브라우저 품질을 보증하지 않는다.

독립 검토는 같은 BFC의 앞선 float 형제가 줄 가용 폭을 제한할 때 새 절대 텍스트 span이 float 회피를 잃는 회귀를 Chrome·WebKit에서 재현했다. 해당 문맥과 음수 margin·효과·생성 콘텐츠·가시 overflow·다른 요소와의 겹침을 보수적으로 제외했다. 후보 수×노드 수 4,096의 검사 예산을 넘을 때도 일반 flow 보정만 생략하며 capture 입력 제한은 바꾸지 않았다. 독립 검토의 같은 Chrome/WebKit 재현 6개에서 회피 배치·글자 paint·원래 겹침 색이 복원됐다. fallback의 기존 줄 재배치까지 해결한 것은 아니다.
