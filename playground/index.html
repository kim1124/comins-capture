GUIDE / SAMPLE EXPORT

설정하고, 결과와 비교합니다.

  1. 파일 형식과 출력 크기를 선택합니다.
  2. 이미지 만들기를 누르고 원본·출력·실제 픽셀 크기를 비교합니다.
  3. 파일 저장으로 결과를 내려받습니다. 초기화하면 설정과 미리보기가 기본 상태로 돌아갑니다.
